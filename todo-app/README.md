# Todo App

A simple and interactive Todo application built with HTML, CSS, and JavaScript to make everyday task management easy and organized.

Add tasks, mark them as completed, and remove them when they are no longer needed, all through a clean, responsive, and user-friendly interface.


## Features

- Add tasks
- Mark tasks as completed with a checkbox
- Completed tasks are shown with a strikethrough
- Delete tasks
- Responsive and user-friendly interface

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Use

1. Type a task in the input box.
2. Click Add to save it to your list.
3. Click a task to mark it as completed.
4. Click Delete to remove it.
