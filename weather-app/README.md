# Weather App

A simple and interactive Weather application built with HTML, CSS, JavaScript, Node.js, Express.js and RESTful API to help users check weather conditions for locations around the world.

Search for a city, state, or country to view its current weather information, including temperature, feels-like temperature, humidity, wind speed, precipitation probability, and geographical coordinates.

## Features

- Search weather by city, state, or country.
- Display the current temperature in Celsius and Fahrenheit.
- Show feels-like temperature in Celsius and Fahrenheit.
- Display current weather conditions and description.
- Show humidity percentage.
- Display wind speed in km/h.
- Show precipitation probability.
- Display geographical coordinates with North, South, East, and West directions.
- Responsive and user-friendly interface.

## Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- EJS
- Axios
- RESTful API
- OpenWeather API

## How to Use

1. Open the Weather App.
2. Enter a city, state, or country in the search box.
3. Click the Search button.
4. View the weather details for the searched location.
