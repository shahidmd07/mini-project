# Simon Says

A simple and interactive Simon Says game built with HTML, CSS, and JavaScript to practice DOM manipulation, event handling, game logic, and user interaction.

The game generates a sequence of colors that the player needs to remember and repeat correctly. The sequence becomes longer with each level, making the game progressively more challenging.

## Features

- Start the game by pressing any key
- Generates a random color sequence for each level
- Allows the user to repeat the generated sequence
- Visual flash effects for game and user actions
- Increases the level after completing each sequence
- Displays the current level
- Tracks and displays the highest score
- Shows a game-over message when the user makes a mistake
- Resets the game for a new attempt
- Provides a visual background effect when the game is over

## How to Play

1. Open the game in a web browser.
2. Press any key to start the game.
3. The game will flash a colored button.
4. Click the same colored button to repeat the sequence.
5. After a correct response, the game will move to the next level and add a new color to the sequence.
6. Remember the complete sequence and repeat it in the correct order.
7. If you click the wrong color, the game ends and your score is displayed.
8. Press any key to start a new game.
