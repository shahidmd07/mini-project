# Simon Says

A simple and interactive Simon Says game built with HTML, CSS, and JavaScript. The game challenges players to remember and repeat color sequences in the correct order, with each level introducing a longer sequence and making the game progressively more challenging.

## Features

- Start or restart the game using the start button
- Generates a random color sequence at each level
- Visual flash effects for game and user actions
- Sound effects for button clicks and game over
- Tracks and displays the current score and highest score
- Displays the final score and level reached
- Progress bar and progress text to track sequence completion
- Game-over background effect
- Option to play again after the game ends

## How to Play

1. Open the game in a web browser.
2. Click the **Start Game** button.
3. Watch the colored button flash and click the same button.
4. Repeat the complete sequence in the correct order.
5. Complete each level to increase your score and proceed to the next level.
6. Follow the progress bar to see how much of the sequence you have completed.
7. Selecting the wrong color ends the game and displays your score and level reached.
8. Click **Play Again** to start a new game.
